# E6C External Gate Register

## Interpretation

`EXTERNAL_GATE` means the repository behavior is ready but an accountable human or external platform must provide a secret, destination, policy, or destructive approval. It is not a product defect and must not be represented as complete. Secrets are referenced by managed handles only and never copied into source, logs, manifests, or evidence.
