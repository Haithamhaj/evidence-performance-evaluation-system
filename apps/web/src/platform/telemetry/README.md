# Product telemetry

Telemetry contains minimized product-use and performance observations only. It cannot feed
orchestration, autonomy, permissions, Project progress, evidence or contribution facts, evaluation,
or manager decisions. It cannot import protected content, credentials, tokens, or domain authority.

The validator analyzes static imports, re-exports, and dynamic imports with literal specifiers. It
does not attempt undecidable closure, alias, container, or reflection value-flow analysis. Runtime
key isolation, the existing provider boundary scan, CI, and human review remain layered controls.
