7. AI Boundaries and Routing

AI Can

Analyze documents, suggest criteria, structure updates, analyze evidence, prepare comparisons, generate coaching, aggregate feedback.

AI Cannot

Assign or recommend ratings, rank employees, resolve attribution as fact, publish unsafe manager feedback, change final evaluations.

Routing

Project override → Department override → System default. Administrator controls every route and records override reason.

Human Approval Gates

Document correction, criteria approval, evidence confirmation, rating selection, justification approval, coaching acceptance, final rating.

Traceability

Every AI run stores route, model configuration, source references, prompt/schema version, output, latency, usage, and fallback state.
